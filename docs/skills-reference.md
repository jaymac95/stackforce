# Skills reference

## Setup
- `/start` — new project: interview, track, stack, state
- `/adopt` — add Stackforce to an existing project (no code changes)
- `/audit [quick | area | path]` — honest review of an already-built project: verdict, scorecard, findings with evidence, and a Now/Next/Later plan
- `/stack` — get or revisit a platform/stack recommendation

## Phases
- `/brief` → `/prd` → `/stories` → `/architecture` (+ `/ux`) → `/build-story` → `/verify` → `/release` → `/handoff`

## Building
- `/build-story [n]` — build the next or a named story, with plan, code, tests, review
- `/team-feature <name>` — coordinate several agents on a larger feature

## Verifying (or run `/verify` to do all for the track)
- `/test`, `/security-check`, `/a11y-check`, `/perf-check`, `/review`

## Any time
- `/status` — where things stand and the next command
- `/decide` — resolve a disagreement between agents
